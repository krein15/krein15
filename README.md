### Backend-разработчик · Python

что происходит **после** написания кода: развернуть на сервере,

**Чем занимаюсь**

### Проекты

**marketplace-parser** — парсер Wildberries, Ozon и Яндекс Маркета: товары,
цены, остатки, отзывы, мониторинг цен, выгрузка в Excel. Площадки
подключаются модулями.
*Через пять дней после публикации по нему пришёл первый заказ на доработку.*

**zakupki-parser** — парсер госзакупок 44-ФЗ: отбор извещений по ключевым
словам со словоформами, минус-словам, ИНН заказчика, региону и сумме.
По каждой закупке видно, **почему она прошла фильтр**.
Результат — Excel и уведомления в Telegram.

**bankruptcy-docs-bot** — Telegram-бот для юристов по банкротству: ведёт
клиента по чек-листу, принимает документы, следит за комплектностью,
напоминает молчунам. Файлы остаются в Telegram, а не на чужом сервере.
*От идеи до работающего бота — два дня.*

**polymarket_tracker** — исследование инсайдерской активности на рынке
предсказаний. Пять недель, 75 000 закрывшихся сделок, девять проверенных
гипотез.
*Вывод отрицательный и доказанный: информированные сделки опознаются,
но заработать на этом нельзя — перевес исчезает за минуты.*

**TradingBots** — бэктестер с честным исполнением и боты в бумажной
торговле. 441 тест, измеренное на бирже проскальзывание вместо
предполагаемого.
